Lancer ou arrêter le service

/home/homelab/Scada-opus-5.5/servir.sh     # démarre le serveur statique (port 8090)
/home/homelab/Scada-opus-5.5/arreter.sh    # l'arrête
Servi par python3 -m http.server 8090 sur 0.0.0.0, journal dans .serveur.log. Il n'y a ni sudo ni service systemd possible sur cette machine (et le linger du compte est désactivé) : le processus est détaché avec setsid nohup, il survit à la déconnexion mais pas au redémarrage. Pour l'automatiser au démarrage, une ligne de crontab -e suffit : @reboot /home/homelab/Scada-opus-5.5/servir.sh.

Ce que ce dossier ne contient pas

Les node_modules du harnais (29 Mo, réinstallables par npm i puppeteer-core) et le fichier de mots de passe du serveur, volontairement exclu. Le harnais s'exécute depuis le PC Windows : il lui faut Node et Microsoft Edge, et il pilote le navigateur, ce qui n'a pas de sens depuis le serveur lui-même. Ses résultats sont inclus ici.
